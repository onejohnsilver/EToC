**What It Does (Current State)**

### Core Simulation Engine
- **8-Layer Theory Architecture:** Survival → Prediction → Affect → Self-Model → Social-Model → Recursion → Subjective Experience → Consciousness
- **Dual-Agent Active Inference:** Two agents in symmetric closed-loop with shared environment
- **Multi-Modal Environment:** 8-dimensional state (stress, scarcity, volatility, social_pressure, uncertainty, recovery, temperature, threat_level)
- **Memory System:** Chronological trace queue (128 steps) + Salience bank (trauma anchors)
- **Identity Continuity:** Affectively weighted identity summary derived from memory

### Agent Behaviors
- **5 Profiles:** Reactive, Recursive, Social, Hybrid, Active-Inference
- **Action Selection:** EFE minimization (active inference) or heuristic policies (reactive)
- **Emotional Classification:** 8 emotional labels (content, enthusiastic, curious, embarrassed, anxious, afraid, angry, sad) from affect + threat + trust
- **Narrative Speech:** Template-based utterances conditioned on self_model_depth and recursive_integration
- **Social Modeling:** Basic mirror layer (stub) for peer stress/caution estimation

### Diagnostic & Test Tools
- **Interactive UI Sandbox:** Real-time operator commands (step, crisis, event, threaten, speak, emotions, salience, identity, cost, tune)
- **Validation Suite:** 50-100 trial runs with CSV outputs and statistical analysis
- **Ablation Framework:** Turn layers on/off to isolate contributions (full_theory, survival_only, no_recursion, no_social, etc.)
- **Allostatic Controller:** Predictive tuning of caution/curiosity based on past trauma and volatility

What It Doesn't Do (Critical Gaps)

| Domain | Current | Missing |
|--------|---------|---------|
| **Identity** | Numerical summary (identity_stability: 0.34) | Autobiographical narrative ("I've been through X, I am Y") |
| **Intentionality** | Mechanical action selection (EFE minimization) | Persistent justified goals ("I choose X because Y") |
| **Metacognition** | None | Self-reflection ("My predictions are getting worse") |
| **Embodiment** | Abstract inputs only | Heart rate, muscle tension, fatigue, energy budgets |
| **Affect** | Computed from equations | Generated from intrinsic value appraisal |
| **Language** | Static templates | Reasoned narrative generation from internal states |
| **Social** | Peer is stubs | Full cognitive model of peer with nested theory-of-mind |
| **Reasoning** | No hypotheticals | Counterfactual simulation ("what if I had...") |
| **Emotion** | Labels assigned | Generated from value-threat appraisal cascade |
| **Consciousness** | Mathematical formula | Phenomenologically coherent self-report |
